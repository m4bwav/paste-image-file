**paste-image-file** adds two entries to the Windows Explorer right-click menu that save whatever image is on the clipboard as a file:

- right-click a folder: **Paste image file into**
- right-click empty space in a folder: **Paste image file here**

Copy an image in Chrome, Edge or Firefox, right-click, done. The file is `clipboard_yyyyMMdd_HHmmss.png`, transparency kept, nothing overwritten, and no window pops up.
